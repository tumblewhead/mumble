Start with [OWNER_RUN.md](OWNER_RUN.md). Pull this branch, build in a fresh scratch directory, run the unchanged two-cell 600-second/35 Hz lifecycle protocol, and selectively push its evidence. No ZIP or private bank is needed.

## Current frontier

V3 retains shared nuisance voltage constraints, including initial-rest pairs. On the original two-cell 180-second prefixes, five of six entering RC-amplitude union widths contracted approximately 9–13% from 8 mV and remained contracted through driven operation. Q remains48–84mAh in both cells. The author recorded 126,000 reported-field and 151,200 same-candidate-coordinate containment checks without sampled misses; independent review checked source, certificate arithmetic, lifecycle witnesses and readbacks, not a separate complete prefix rerun.

The full 600-second V3 acceptance run is **not executed**. The 100-frame harness benchmark completed 400 updates in 9.16 seconds; owner full-run runtime is estimated 20–45 minutes, possibly longer. Neither execution nor sampled containment establishes physical accuracy, probability coverage, indefinite useful operation, full historical sufficiency or M23 readiness. Exact-rational verification applies to LP query certificates, not the complete physical solver.

## New publication scope

This is the explicitly approved runnable-source package, not the older complete archival checkpoint. Compiled objects, bulky historical outputs and obsolete draft copies are not included. All prior artifacts remain unchanged in owner-held archives. [ARCHIVED_EVIDENCE.json](ARCHIVED_EVIDENCE.json) provides archive identities and per-file hashes for the omitted material, plus origin bindings for retained source. Public readers do not automatically have access to those private archives.

Current reviewed model, priors, measurement supports, protocol, gates and V3 estimator sources are retained without scientific changes. Only owner-path tooling/documentation is adapted for this repository location. The initial-rest estimator is a desktop Python/native-C diagnostic with bounded retained rows and explicit relaxations, not the complete manuscript estimator or an M23-sized implementation.

[RUN_CONTRACT.json](RUN_CONTRACT.json) specifies the owner experiment; [SOURCE_MANIFEST.json](SOURCE_MANIFEST.json) binds the published source. All eight estimate and seven task families remain distinguished in [harness/CAPABILITIES.json](harness/CAPABILITIES.json).
