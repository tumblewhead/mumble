# A1: within-observation reuse of H7 hysteresis coefficients

## Admitted execution and numerical premises

The response ABI is n=6,m=8,b=36, width112, state167binary64values. Arrays have
valid lengths and do not overlap any input/configuration or output storage in
a way that writes alter later reads. Configuration, rates and projection tables
are immutable for a call. There is one synchronous owner; no concurrent mutation.
Finite admitted observations have dt in[0,1], |I|<=.25,T in[15,35],sigma>0;
calibration/rates are valid positive-response inputs and all arithmetic used in
the returned value is defined and finite. Identical finite initial states and
identical input bytes are supplied to both kernels.

Assume elementary arithmetic is performed with the same binary64 rounding and
expression grouping in both programs, without contraction/reassociation or
excess intermediate precision. exp/expm1 are deterministic functions of their
argument bits under one fixed arithmetic environment. Storing/reloading their
results as double preserves these bits. Observables are response status, written
valid-prefix response row bytes and state bytes. Full output-buffer comparisons
additionally require identical initial output bytes: count=0 or an invalid-prefix
return may leave an unwritten suffix, which both kernels leave untouched. errno,
floating-point flags/traps, timing, function-call
counts and asynchronous faults are not included in this value-equivalence claim.
Their absence is a qualification premise, not a universal C/libm guarantee.

## Reuse lemma

For one nonzero-current observation define a(q,r) by the reference expression

    rate = I>0 ? rates[18+q] : rates[26+r]
    a = rate*f[I>0?9:10]*fabs(I)*dt/(3600*f[0]).

The ordered operands of this expression depend on q alone if I>0, and on r
alone if I<0. Nothing in Eh/uh or the row projection enters a. Hence the64grid
positions have8active argument choices. Evaluating exp(-a) and -expm1(-a) once
per active index yields exactly the same pair of bits the reference would obtain
at every position using that index, under the numerical premises above.

The candidate fills two8element arrays before the q/r loop. Each lookup uses q
for positive and r for negative current. It then performs the identical updates

    Eh[ix] *= decay;
    uh[ix] = decay*uh[ix] + one*(I>0?1:-1);

in the identical row-major order. Induction over ix preserves all64pairs. The
SOC, RC and row-projection expressions and orders are unchanged; therefore the
entire outgoing state and row are bitwise identical. For I==0 (including signed
zero), both skip all hysteresis operations. For dt==0,I!=0 both still execute
the same updates with the same signed-zero exponential arguments.

Induction over observations extends the result to any finite admitted call and
any common chronological partition of calls. An invalid observation is rejected
by the same predicate before its mutation in both programs; any valid preceding
prefix of the call remains identically mutated. The primitive is not itself a
transaction. Callers needing atomicity must retain their existing staging.

## Resource and integration consequences

Per nonzero-current observation, explicit hysteresis exp/expm1 evaluations fall
from64pairs to8pairs; all64state updates remain. Source-level full response counts
are exp93->37 and expm1 82->26; at rest both remain exp29/expm1 18. This does
not predict machine cycles or whole-estimator speedup. Compiler-emitted call
counts require inspection or instrumented builds.

No persistent state or coefficient format changes. The candidate adds two local
arrays,16doubles=128B payload; compiler stack allocation and total peak call-chain
stack are separate measurements. Values expire within each observation, so no
cross-observation key, invalidation, registry or rate-freezing assumption is used.

When the same downstream kernels consume identical rows/states in the same order,
their value behavior is preserved under their unchanged runtime premises. Tests
must cover both standalone field response and fused tangent paths; unchanged
domain failures must remain failures. This does not repair approximation error,
rate-box exit, recovery iteration budgets, physical coverage or M23 resource limits.
The candidate explicitly rejects other ABI dimensions; no equivalence is claimed
for the reference's broader dimension interface.
