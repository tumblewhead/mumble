# J1: joint error, fit displacement and query uncertainty

This consolidates symbolic_system_001/U1, joint_precision_attribution_001/M1 and
rc_remainder_bounds_001/P3. Premises: identical evidence, differentiable normalized
residual r(theta), approximate residual r+e, identical twice-differentiable prior
cost pi, and an interior common support point. Jacobians are J=Dr, E=De; parameter
derivatives include the entire physical state/parameter coordinate chain. No
independent-parameter assumption is made. Claims are exact arithmetic; empirical
coverage, numerical certification and nonlinear global optimization are separate.

Let Phi=pi+||r||^2/2 and Phihat=pi+||r+e||^2/2. Direct expansion gives

    Delta Phi = r^T e + e^T e/2,
    Delta g = J^T e + E^T r + E^T e,
    Delta P = J^T E + E^T J + E^T E.

Here P=Lambda+J^T J is Gauss-Newton precision using the identical quadratic-prior
precision Lambda, and Phat=P+Delta P. The first two identities need not assume a
quadratic prior because it cancels. The exact Hessian difference, for C2 r,e, is

    Delta H = Delta P + sum_i e_i Hessian(r_i)
                             + sum_i (r_i+e_i) Hessian(e_i).

Thus a small residual defect does not alone control precision or fit displacement;
the Jacobian error can couple to the realized residual. If e=sum_a e_a then
Delta g contains sum_(a,b) E_a^T e_b and Delta P contains sum_(a,b) E_a^T E_b.
Even additive response families do not have additive norm/error budgets unless
cross terms are bounded explicitly. Reducing one component can remove beneficial
cancellation; it need not improve total error or every parameter.

## Exact linearized fit identity and nonlinear limit

Suppose r,e are affine and pi is quadratic, theta* is the exact minimizer of Phi,
and P is positive definite. Set A=P^(-1/2) Delta P P^(-1/2),
b=P^(-1/2) Delta g(theta*). If Phat is positive definite, the approximate minimizer
satisfies exactly

    z=P^(1/2)(thetahat-theta*)=-(I+A)^(-1)b.

Proof: the approximate gradient is Delta g(theta*)+Phat*(theta-thetastar);
solve it and whiten. If ||A||_2<=epsilon<1, then
||z|| <= ||b||/(1-epsilon). This controls joint displacement, not a separate
error allocation per parameter, and is exact only for these quadratic objectives.

For a smooth nonlinear model introduce residual r+alpha*e. If theta* is an interior
stationary point with nonsingular exact Hessian H, the implicit function theorem
gives the local stationary branch derivative

    d theta(alpha)/d alpha at0 = -H^-1 (J^T e+E^T r) at theta*.

This requires C2 objectives with the needed differentiability of the gradient,
and concerns sufficiently small alpha. It does not justify replacing H by P,
evaluating at alpha=1, crossing a support boundary, or asserting a global minimum.
Our previous fitted joint discrepancies are measured diagnostics, not this theorem.

## Queries and transport are part of the same geometry

For a vector query q(theta) at a fixed anchor define G=Dq, compressed gradient
Ghat=G+Delta G, T=G P^-1/2 and D=Delta G P^-1/2. Then exactly for local GN covariance

    Cq = T T^T,
    Cqhat = (T+D)(I+A)^-1(T+D)^T.

This follows by factoring Phat=P^1/2(I+A)P^1/2. A query such as proposed-load
voltage must differentiate through incoming-state transport. A wrong likelihood
and wrong transport can compensate, so check both G and Ghat. Mean query error
also includes the same-anchor qhat-q and movement of the fitted parameters;
for a small displacement it is (qhat-q)(theta*)+Ghat(theta*)*(thetahat-theta*)
plus the query Taylor remainder. No variance-only criterion bounds that mean error.

An invertible local coordinate change with derivative S maps gradients to S^T g,
GN precision to S^T P S and query derivatives to G S. Delta g^T P^-1 Delta g,
generalized eigenvalues of (Phat,P), and query covariance are invariant. This is
a local congruence statement, including a prior represented consistently. It does
not apply to replacing a nonlinear prior by a different Gaussian. Changing chart
labels cannot remove physical bias; changing the approximating function in a new
coordinate can help, but must be measured anew under the same physical metric.

## Design consequence

Use a declared joint objective: whitened score defect b, relative precision A,
query mean/transport defects, full support/ownership, and resource cost. Application
tolerances belong to SOC/Q/proposed-load queries; weak nuisance directions still
need their cross-coupling retained. This gives a way to expose shifted error,
not a theorem that one compact representation can satisfy every budget.
