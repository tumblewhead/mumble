# K0 — Exact observable refinement

## Definitions and assumptions

R and C are reference and candidate machines. A macrostep consumes one external
event u (sample, query, reset, or an admitted fault) and produces a finite public
word o. The word includes source/consumption/publication identities, estimates,
uncertainty, authorization and status, and externally visible side effects.
An internal representation is unobservable only if the interface says so.

Let S relate states of R and C. Assume:

1. Initial states are related. Admitted event sequences are specified by a common
   prefix-closed environment contract, including any fairness assumptions.
2. At every related pair and admitted next u, at least one C macrostep is enabled.
   Every possible C macrostep
   terminates and can be matched by an R macrostep with the same public word,
   ending in related states. This premise includes all admitted faults and
   interleavings. For deterministic R the matching step is unique.
3. Macrostep interfaces account for every public observation. Internal steps
   cannot publish extra words, consume hidden evidence, or diverge.

These are implementation obligations, not properties inferred from testing.
The reference properties below must hold on every matching reference execution.

## Theorem and proof

Every finite C event trace has a matching R trace with identical public words
and related final states. Proof by induction on event count n. At n=0, assumption
1 supplies the related states. For the induction step, use assumption 2 on the
related final pair and the next common u; concatenate its identical word and
retain its related successor. Assumption 3 excludes an unmatched internal event.
This proves the statement for every finite n and every admitted C choice.

Consequently every property determined by finite public prefixes transfers from
R to C. If R guarantees an authorization by at most m subsequent admitted events
in a specified scenario class, the same identical word appears by event m in C.
An infinite C execution with infinitely many completed macrosteps has an infinite
matching R execution, constructed successively using assumption 2. Logical
liveness transfers only for executions satisfying the shared environment/fairness
contract. The theorem does not create future inputs or resolve unfair scheduling.

Real-time availability is a separate corollary: if the timed interface is matched,
or a verified C scheduling bound places the required public word before the same
deadline, that deadline is preserved. Per-call termination or average speed alone
does not supply this premise. Timers, interrupts and wall-time-dependent faults
must be included in the timed environment; identical sample indices are insufficient.

## Guard specialization corollary

Suppose reachable reference states at an internal point satisfy predicate P,
and a guard has no externally observable effect other than selecting between
branches by P. Replacing it with its P-true branch preserves that local transition.
If S's other transitions remain valid, the theorem applies. The proof is substitution
of P=true into the branch semantics followed by the induction above. All entry
points and intervening mutations must preserve P. Floating-point status flags,
volatile reads and timing are effects if the declared interface observes them.

## Scope

This is a simulation theorem, not proof that a particular optimized kernel meets
its transition premise. Real-arithmetic objective equality does not imply bitwise
or trace equality. An exact optimization preserves reference defects too. No
deployment, guard removal or target deadline is certified by this generic lemma.
