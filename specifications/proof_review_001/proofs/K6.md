# K6 — Grouping, cadence and closed-loop behavior

## Exact grouping theorem

For each ordered input u_i and observation y_i let a deterministic row generator
give (s_(i+1),a_i)=G(s_i,u_i,y_i). Fix initial s_0 and the model/configuration.
Assume grouping boundaries do not change G, its arguments or generated rows.
Each sample is generated once, and groups partition the prefix without gaps.
Then all groupings produce the same state sequence and rows. Proof: the base
state is fixed; identical s_i,u_i,y_i give identical next state and row by
determinism. Induct over samples, regardless of the chosen boundaries.

For a common feature map phi, in exact arithmetic

    sum_groups ||A_group phi||^2 = sum_i (a_i phi)^2.

The equality follows by partitioning the finite sum. Any exact QR root with
R'R=sum_i a_i'a_i represents this same quadratic. This says nothing about
bitwise QR order or an adaptive row generator whose model/anchor changes at
boundaries. Such cases violate the stated fixed-generator premise.

An H7 tangent relinearization can alter the approximation even though the full
feature likelihood is unchanged. Different solve counts/anchors must therefore
have a separate error/decision argument. A stale readout must be transported to
the requested physical prefix with a valid error bound. No evidence equivalence
statement eliminates actual dt or authorizes dropping an observation.

## Exact closed-loop theorem

At discrete external events let a deterministic controller update its own state
and choose an action from the estimator's public word and the event timing. Let
a deterministic environment generate the next observation/state from the action
and a fixed exogenous disturbance sequence. Both executions start with identical
controller/environment states and disturbances. Assume the estimators satisfy
exact public-word refinement for every common input prefix, including all timing
information used by the controller/environment. No unmodeled execution delay
changes sampling, actions or disturbances.

Induction proves identical actions and observations. Initially the states and
input prefix match. Estimator refinement yields identical public words; controller
determinism gives identical next controller states/actions; environment determinism
with the same disturbance gives identical next physical states/observations.
This reestablishes the common-input premise for the next event. If disturbances
are stochastic, a common exogenous coupling with matching marginals yields
pathwise equality under that coupling and hence equality in distribution.

## Bounded rather than exact changes

Common-input numerical bounds alone do not establish a common future input when
the controller uses those outputs. One sufficient route is to prove decision
margins for every reachable pair of estimator/controller states, including any
changed controller memory, so that actions and their timing remain identical.
Another route defines a joint state (plant, estimator, controller) and proves a
Lipschitz or set-valued reachability bound for the entire transition. A margin
checked only once or on the reference path is not that proof.

As a counterexample, a controller choosing +1 for estimate>=0 and -1 otherwise
selects different actions for arbitrarily close estimates +epsilon and -epsilon.
Thereafter matched-input replay no longer describes its realized closed loop.
Different actions can both be certified safe, but their availability and future
excitation are a new policy claim rather than exact behavioral preservation.

## Scope

No H7 cadence, controller, acquisition delay or closed-loop approximation constants
are certified here. The exact grouping result concerns the fixed row generator;
the exact control result requires timed public equivalence and an explicit
environment model. Their premises cannot be exchanged for each other.
