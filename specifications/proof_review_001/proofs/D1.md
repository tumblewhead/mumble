# D1 — Conservative propagation and evidence containment

## Definitions and premises

The true state x_k includes all physical/parameter/latent quantities needed for
the following transition relation to be valid. Let U_k contain the true input
u_k and let x_(k+1) belong to F_k(x_k,u_k). F_k may include aging and model error;
it need not be deterministic. C_k is a joint set intended to contain x_k.
Let Y_(k+1) contain every state compatible with the new observation under the
qualified measurement assumptions; in particular it contains the true successor.

Assume initial x_0 in C_0. At each step compute an outer reach set R_k such that

    R_k contains union_(x in C_k,u in U_k) F_k(x,u),

then a stored representation decoding to C_(k+1) that contains
R_k intersect Y_(k+1). These inclusions include approximation, compression and
rounded computation. Inputs and states may be correlated: their Cartesian product
is simply an outer set of the admissible joint possibilities. A tighter joint
input/state relation is permitted if it still includes the true pair.

## Theorem and proof

Under these premises x_k in C_k at every finite step. The base is assumed. For
the step, the true x_k,u_k are in the reach union and their true successor belongs
to F_k(x_k,u_k); hence it is in R_k. Measurement validity puts it in Y_(k+1).
It therefore belongs to the intersection and the decoded superset C_(k+1).
Induction proves the assertion. This proof is pathwise and uses no independence.

If all these premises hold jointly on an event E with probability at least
1-alpha, simultaneous containment holds on E with the same bound. This does not
construct or validate E. Per-step probabilistic bounds require valid composition
to obtain E; infinitely many Gaussian errors do not have an arbitrary finite
hard envelope merely because their variance is known.

## Missing data and representation corollaries

With no new observation choose Y as the entire state space: prediction alone
preserves containment. Missing current/temperature require sets U containing
their unknown true values, not substitution of zero input. Unknown interval
length must likewise be included among the transition inputs. Dropping a
likelihood observation can enlarge a conservative set but cannot claim identical
information or unchanged availability.

Any replacement representation decoding to a superset preserves the invariant
by transitivity. Product marginal boxes can be such a superset but may be much
looser than the joint set. They do not preserve joint posterior mass/likelihood.
Inconsistent marginal approximations or inward rounding need not be supersets.
If a computation returns an empty set, the premises and true-state containment
cannot all hold; no arbitrary point or normalization repairs that contradiction.

## Scope

This is a sufficient containment contract, not a proposed full trajectory-set
implementation. Bounded storage and useful contraction require additional proofs.
Initial support must cover an aged cell after lost history. Clipping a point,
using an unqualified drift model, or preserving a local Gaussian covariance does
not discharge the reach/measurement inclusions. Hardware/model/sensor premises
and Mumble implementation correspondence remain open.
