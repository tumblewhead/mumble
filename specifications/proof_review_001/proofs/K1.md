# K1 — Perturbation, decision margins and solver residuals

## Assumptions

Reference states x_k and candidate states z_k are embedded in one normed space.
Both remain in a declared domain Omega_k. For the same external input u_k write
x_(k+1)=T_k(x_k), z_(k+1)=S_k(z_k). For every relevant pair in Omega_k,

    ||T_k(x)-T_k(z)|| <= L_k ||x-z||,
    ||S_k(z)-T_k(z)|| <= e_k,

with finite nonnegative bounds L_k,e_k. Let b_0 bound ||z_0-x_0||. Domain
invariance, including every possible branch, is a separate premise. If a premise
fails the bound cannot be used to authorize an output. Norms/units are fixed.

## State and query theorem

Define b_(k+1)=L_k b_k+e_k. Then ||z_k-x_k||<=b_k for every admitted k.
The base is the definition of b_0. For the step, insert T_k(z_k), apply the
triangle inequality and both assumed bounds. Induction proves the result.
Repeated substitution gives

    b_N = (product_(k=0..N-1) L_k)b_0
          + sum_(j=0..N-1) e_j product_(k=j+1..N-1) L_k,

where an empty product is one. This identity follows by multiplying the N-step
expression by L_N and adding e_N. If a query f is L_f-Lipschitz and its computed
candidate f_C has ||f_C(z)-f(z)||<=eta on the domain, another triangle inequality
gives ||f_C(z_k)-f(x_k)||<=eta+L_f b_k. The bound's own arithmetic must be outward
enclosed. There is no root-sum-square cancellation assumption.

## Decision theorem

For real margins g_R,g_C with |g_C-g_R|<=delta, delta>=0, define reference
acceptance as g_R>=0 and conservative candidate acceptance as g_C>=delta.
Candidate acceptance implies g_R>=g_C-delta>=0. Conversely g_R>=2delta implies
g_C>=g_R-delta>=delta. Therefore all reference decisions with that positive
margin are retained; other reference acceptances may be refused. If |g_R|>delta,
the unguarded signs agree. Boundary equality follows the declared >= convention.
The pair (g_R,g_C)=(epsilon,-epsilon) shows that small error alone permits a
decision flip. Safe refusal and availability are distinct obligations.

The delta must bound the actual decision function, including changed state,
uncertainty, transport and numerical evaluation. It cannot be inferred just from
a voltage residual or one parameter error. Reference acceptance must itself have
a valid safety interpretation. Branch changes require this argument at every
relevant step or an error bound covering both branches.

## Solver corollary with explicit premises

Let F be twice continuously differentiable on a convex region containing an
interior stationary minimizer x* and candidate z. Assume Hessian F >= P everywhere
on their segment for a fixed SPD P. Put d=z-x*. Integration gives

    d' grad F(z) = integral_0^1 d' Hessian F(x*+td) d dt >= d'P d.

Metric Cauchy-Schwarz bounds the left side by ||d||_P ||grad F(z)||_(P^-1).
For d!=0 divide by ||d||_P; for d=0 the same conclusion is immediate:
||z-x*||_P<=||grad F(z)||_(P^-1). A query gradient bounded by L_f in the dual
P metric on the segment gives error <=L_f||grad F(z)||_(P^-1), plus any query
evaluation defect eta. These are reference gradients, not candidate gradients.
An interval bound on reference gradient error can enclose the former from the
latter by the triangle inequality. Local GN precision is not automatically a
Hessian lower bound. Iteration caps guarantee neither this premise nor accuracy.

## Scope

No H7 domain constants, global mode proof, or target numerical bound is supplied.
Closed-loop changes to u_k require a coupled system argument, not this common-input
theorem alone. These are deterministic implementation-error bounds, not calibrated
physical uncertainty or lifetime statistical coverage.
