# Symbolic development across the estimator

This is the working plan authorized after hysteresis_relationships_001, at base
revision dbd6a10 on experiment/conditional-architecture-001. Discoveries may change
candidate representations and experiment order. Preserve failed hypotheses and
original evidence; explain each adaptation before accepting a replacement.

The sequence for each question is physical identity -> approximation defect ->
application consequence -> targeted intervention. A conditional proof, a finite
implementation witness, and real-cell/target qualification are separate results.
Every proof and optimization requires independent review, including substantive
revisions. No firmware, coverage or ten-year claim follows from this first tranche.

This first tranche derives and checks all four relationships without changing a
production kernel. It extends the existing H1-H4, A0-A8, S1 and D/K collections;
it does not replace their ownership, normalization, support or resource contracts.
The RC native check is a bounded deterministic control, not a new long campaign.

## Discovery and decision rules

1. Record a new identity, counterexample or observed discrepancy with its scope.
2. If it changes a premise, preserve the old claim and write a revised packet;
   do not reinterpret a passing finite probe as a domain-wide theorem.
3. Prefer the smallest intervention that tests the identified mechanism. Preserve
   the joint likelihood, source order, actual intervals and state transport.
4. Score representation error through SOC, capacity and proposed-load voltage,
   alongside full joint uncertainty, unresolved directions and complete resources.
5. A change advances only after independent proof/code review and matched controls.
   Long campaigns and Monte Carlo confirmation follow a frozen viable candidate.
