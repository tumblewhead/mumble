# A6 — Continuous support, numerical approximation and error accounting

## Representation interface and invariants

Choose a frozen reference physical likelihood/state relation, original prior,
base measure, support and source prefix. A representation evaluates that declared
joint object approximately over continuous parameters; a codebook encodes its
coefficients/shape, not a list of allowable batteries. A0 supplies a restricted
dependency map, not permission to discard cross terms or Gaussianize support.

Each replacement/quantization/recentering/relinearization carries a comparison
domain, reference identity, method and certified defect or explicit provisional
status. Distinguish physical-model/input error, response approximation, storage
rounding, accumulator arithmetic, solver residual and endpoint/query transport.
Unknown error is not zero. The bound arithmetic itself must be conservative.
Finiteness, support, positive precision when required and bounded solver work
are invariants; a domain exit is not physical exclusion or proof of divergence.

## Conditional composition theorem

On the same nonempty domain D, base measure and prior, let F_i be successive finite
negative log densities with finite positive normalizers. If the uniform
oscillation of each F_i-F_(i-1) is<=omega_i, telescoping at any two parameter points
gives osc(F_m-F_0)<=Omega=sum omega_i. Reviewed K2 then gives
TV(pi_m,pi_0)<=tanh(Omega/4). This is comparison of normalized model distributions,
not calibrated physical coverage. Parameter-independent constants cancel in this
comparison but may affect solver stopping/normalizer interfaces and cannot simply
be deleted from code without another argument.

For evidence blocks represented as sums on the same coordinates, their uniform
error bounds add by the same triangle inequality. For sequential state maps with
uniform Lipschitz L_k and local defect e_k on invariant domains, K1 gives
b_(k+1)=L_k b_k+e_k by inserting the reference map and applying triangle inequality.
Query error adds its evaluation defect and the transported state-bound contribution.
These are different ledgers: do not use a likelihood oscillation as a state error,
or add all local state defects without their downstream amplification. Each
representation must justify how block maps/domains are aligned before applying
either rule; unknown coupling is a failed premise, not an independent-noise term.

Joint local precision comparisons must use common coordinates and K2's matrix
order/product bounds, not a sum of marginal variance percentages. A solver-gradient
bound implies a center bound only with the reference curvature/domain conditions
of K1. The local GN matrix and an iteration-limit return do not prove those
conditions. Finite direct-history probes are diagnostics, not uniform bounds.

## Domain adaptation and long-run requirements

Keep physical support distinct from the computational domain on which a basis is
valid. A proposed step outside that domain must be constrained with a justified
solver strategy, migrated to another qualified representation, rebuilt from owned
evidence, or reported unresolved. Widening a box changes its approximation problem.
Clipping a parameter silently changes inference. Moving a basis cannot reconstruct
discarded shape dependence from a fixed-rate statistic. Retained-domain posterior
claims require separate accounting for excluded mass if the physical reference
has wider support; do not set that mass to zero because the compressor lacks it.

Over the declared ten-year horizon, require uniform useful budgets or a qualified
strategy to recover/refine/enlarge the representation within A8 resources. A
constant per-sample bias can become significant relative to accumulated precision.
Bounded storage and stable endpoint RC decay do not erase old likelihood errors.
If a budget cannot be sustained, reduce authorization with the actual error or
enter an explicit unresolved state; do not invent forgetting or inflate covariance
without an interpretable physical/statistical model. A promised refinement must
identify what retained data permits it and its cost.

## Acceptance and unresolved parameters

Before selecting approximate kernels, allocate numerical/representation/query
budgets from the application tolerances against the frozen reference; posterior
fidelity and physical point-error targets are distinct. Require supported-domain
value/gradient/transport controls, worst-case or certified bounds, precision/PSD
checks, repeated/weak/reversal stimuli, time-prefix scaling, domain-migration
failures and preserved original evidence. Independence/cancellation cannot be
assumed to make coherent approximation errors disappear. Architecture changes
that alter acquisition/actions also require A8 closed-loop qualification.
This packet specifies composition of valid bounds; no concrete continuous-rate
basis, uniform constants, ten-year budget or calibrated model has been supplied.
