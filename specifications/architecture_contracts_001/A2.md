# A2 — Cache and dependency validity

## Interface, premises and invariant

A pure computation consumes an ordered tuple of immutable values or uniquely
identified immutable generations and a versioned model/arithmetic configuration.
It returns a value or declared error. A stateful transition is a distinct effect;
its receipt is not interchangeable with a pure result. A cache stores completed
key/value/error records, with bounded residency and atomic publication of the pair.

The invariant is: every reusable entry equals a fresh evaluation under the same
observable semantics. The key must include every dependency influencing that
result, including kernel/calibration/model/coordinate/support versions, precision
and arithmetic environment when variable. Generations must not wrap or be reused
while any reference/cache entry can survive. Eviction invalidates the entry before
its bytes are reused. A digest alone is not a collision-free semantic identity.

For thermal factors the numerical inputs include T and thermal calibration. RC
coefficients add actual dt and rates. Directional hysteresis coefficients add
signed current and the directional parameters. Anchor/basis derivatives depend on
anchor and representation generations. Query results additionally depend on the
committed evidence/state prefix, query definition and horizon. This is not a
complete implementation key layout; tracing actual kernel operands must discharge
each dependency list. Rate changes cannot reinterpret accumulated fixed-rate
history as though it had been generated at the new rates.

## Conditional theorem and proof

Assume a deterministic total pure kernel f on admitted inputs z, and a key K such
that K(z)=K(z') implies equality of f(z),f(z') in every downstream observable.
Assume a hit returns the completed stored f(z'), without side effects or stale
generation races. Substitution gives hit(z)=f(z')=f(z). A miss evaluates f normally
and publishes only its completed result; eviction changes cost, not this equality.
Induct over topologically ordered pure nodes of each invocation. Equal predecessor
values give equal outputs, including matching declared errors. Streaming effects
are serialized separately by A4, so this induction cannot omit or repeat a state
transition. This instantiates reviewed K3; it does not prove a concrete key complete.

For bitwise refinement, equality includes signed zero and admitted NaN semantics;
the preferred admitted numerical domain excludes nonfinite values. Algebraic or
display equality is insufficient if a downstream division, branch or derivative
distinguishes the inputs. errno, floating flags, traps and external reads/writes
are either excluded by an explicit runtime contract or reproduced as effects.

## Approximate reuse and failure behavior

Approximate keys are a different A6 operation. Fix input/output norms. Suppose
both query z and representative z' belong to the same supported bucket on which
f is L-Lipschitz, ||z-z'||<=d, and stored y' satisfies ||y'-f(z')||<=eta. Then
triangle inequality gives ||y'-f(z)||<=eta+Ld. A nearby representative outside
that certified bucket is not covered by this argument. Derivatives and transported
uncertainty need their own included bounds. This per-use defect enters A6's
cumulative ledger; repeated hits are not independent noise. Discrete configuration
changes cannot be rounded into a bucket without a separate valid comparison.

On incomplete key, unknown generation, unsupported input or invalidated storage,
compute a fresh supported result if resources permit; otherwise return unresolved.
A cache miss is not a physical exclusion. A cached error cannot be relabeled as
success. Prefix-dependent query/authority results are invalidated when their
prefix changes; pure prefix-independent coefficients may survive if their full
dependency key still matches. Model changes invalidate all affected results.
Failed fills never publish partial values. Exhaustion/eviction costs belong to A8.

## Required witnesses and open premises

Before implementation acceptance: independently perturb each actual dependency;
exercise repeated hits, cold misses, sign/direction changes, near-boundary inputs,
failed fills, eviction and attempted generation reuse; compare with uncached
semantics. Fault/concurrency tests must match the claimed synchronization model.
An intentionally omitted temperature/rate/epoch key must be detected. Inspect
complete key storage, lookup/miss bounds and alias lifetimes under A3/A8.
No persistent cache is implemented or certified by this contract. Cache hit rate
and future population/aging assumptions do not discharge key completeness.
