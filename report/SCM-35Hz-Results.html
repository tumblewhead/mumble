What is implemented

The C implementation estimates three RC modes, ohmic resistance, asymmetric throughput hysteresis, capacity, initial SOC and entering dynamic states. It also reports an individual status and uncertainty diagnostic for each target. A numerical point remains visible without being presented as known. Earlier observations are carried forward by replaying the complete observed history at each checkpoint.

This is a host reference, not a completed Cortex-M23 port. The physical propagation and assessment modules use fixed-size caller-owned memory, but the fit and explicit projection construction still allocate history-sized buffers. The package contains source, data, reproducible runners, verification receipts and this report.

Experiment contract

Each run ingests 73,500 point observations over 2,100 seconds at 35 Hz. Current is piecewise constant during each interval and terminal voltage is measured at its end. Current, timing, the OCV curve and temperature are exact in this experiment; voltage noise is independent Gaussian with 1 mV standard deviation. Both synthetic cells have constant parameters and the generating model matches the fitted model.

The actual numerical measured OCV–SOC table was not provided, so this run uses the explicit illustrative curve U(z)=3+1.15z+0.08 tanh(8(z−0.5)) V. The executable accepts a measured monotone 25 °C table through --ocv. These results therefore establish behavior under a known curve, not performance on the user’s measured cell.

The estimator explicitly reports unresolved quantities

The C assessment distinguishes unexcited, unresolved and provisional. Unexcited means a supported structural check finds the relevant stimulus absent. Unresolved includes null directions, excessive uncertainty, numerical limits and unsupported coordinate charts. Provisional means a finite local range passes an engineering precision screen; it does not assert nonlinear or real-world validity.

The assessment uses the undamped joint likelihood matrix, with the correct cross-covariances for current SOC and h₀=u₀/H. A target with a material component in a numerical null direction retains its declared support. A pseudoinverse is never used to turn an unobserved direction into zero variance. Bounds are not used to clip a range into apparent precision, and a near-zero hysteresis amplitude makes the h₀ ratio unavailable.

Default screens use a two-sigma half-width of at most 10% for positive physical parameters and five percentage points for SOC. These are configurable thresholds on a local approximation, not calibrated probability statements. Entering nuisance states have no automatic release threshold.

A stricter reporting screen can be evaluated without looking at truth. The following times require a usable local range at every remaining checkpoint. SOC and capacity pass the stricter 0.5 pp / 0.5% screens at the same checkpoints as their empirical accuracy crossings; the fast pole and R₀ show the gap between point accuracy and supported precision.

These brackets use a Δnegative-log-likelihood threshold of two relative to the lowest observed feasible cost. They are finite-grid local-optimization evidence, not global exclusion proofs or calibrated confidence intervals. A low-cost feasible candidate can serve as a witness. An unfinished high-cost optimization cannot justify an outside boundary; that side falls back to declared support when no converged outside point is available.

The 29 selected profiles produced 369 numerical candidates: 296 met stopping criteria and 73 did not; one additional attempted fit failed operationally. All returned candidates were independently evaluated. No heuristic bracket uses an unfinished outside point. One extreme, high-cost, unfinished candidate had sub-10⁻¹⁶ V amplitude-bound roundoff that made a naive u₀/H ratio invalid; the reporter now suppresses that near-zero ratio. It did not affect accepted profile points.

The main 60-fit campaign had 50 numerical successes and ten iteration limits. A same-prefix capacity profile found a 220-second solution with a negative log likelihood lower by 5.861133. An unrestricted refinement confirmed it, but capacity stayed near the 100 mAh search bound and SOC error remained about 2.82 percentage points. The original campaign is preserved and the refinement is saved separately. This is evidence for retaining the early “unresolved” designation, not silently replacing a difficult result.

Carry evidence through weak use

The final five minutes alone have insufficient information to recover the history. The full-history fit retains the earlier pulse and reversal evidence. A fresh fit to just the quiet tail has unknown entering states and cannot reliably separate SOC and capacity, even while fitting voltage closely.

This identity shows the limitation. Compression retains the first term. If every relevant sensitivity direction lies in the retained basis, the first-order information is preserved at that anchor. Feature payload reduction is not firmware memory reduction. The explicit one-anchor representation retains about 9.0 MB on this host, and hybrid about 24.4 MB; their fitting plus basis construction is slower than the roughly 3-second full fit. The numbers support pursuing compact analytical event accumulators rather than claiming that this explicit basis implementation meets the MCU budget.

Verification and execution scope

C performs all model propagation, optimization, projection and final qualification. Python generates synthetic traces, orchestrates jobs, recomputes physical predictions independently, scores truth errors and draws these figures. The complete command, initial guess source, binary/source hashes, return status and numerical diagnostics are retained for each fit.

  • All 60 main candidates were independently recomputed; maximum absolute raw-objective discrepancy was 2.33×10⁻⁸.
  • The C forward model and independent predictor agreed over 147,000 truth-generated samples to about 1.46×10⁻¹² V.
  • Finite-difference, state-carry, ordering, rest ambiguity, projection, constraint restoration and public-API canaries are included.
  • The C and Python qualification layers agree across 61 stored fits and 1,098 target reports; no optimization was repeated for that comparison.
  • The final CLI assessment integration was checked against the preserved benchmark executable with identical commands. Core fit outputs are unchanged.
  • Address/undefined-behavior instrumentation was used on the estimator test; leak scanning and MCU stack/cycle measurements were not performed.

Across the six final full-history campaign fits, median host C CPU time was 2.832969 seconds. This is time for a complete retrospective prefix fit, not per-sample inference latency. It is not transferable to a Cortex-M23. Main full-fit retained allocations total 49,394,072 bytes, including 47,040,000 bytes of cached rows. The fixed physical state is 280 bytes, model row 648 bytes, assessment workspace 4,224 bytes and assessment output 2,488 bytes on this host. A complete SRAM/stack budget remains to be designed.

Next engineering step

The next implementation should make every event update conditional on the directions it can support, retain earlier qualified evidence and track its age and compatibility, and propagate SOC continuously between slower parameter updates. A residual inconsistency check must reopen uncertainty when the cell or operating regime changes. The current experiment uses constant parameters and does not validate aging or drift handling.

For bounded memory, candidate approaches include exact event accumulators for a fixed model chart, a bounded set of retained excitation windows, and controlled relinearization with a residual guard. Their validity must be compared against this replay reference. A word can then be scored by its marginal contribution given existing evidence and its entering state; a universal context-free catalog of useful token strings would miss that dependence.

Repeated independent observations reduce noise in already observed directions, but cannot create an absent direction. Retaining a normalized average without count, variance or correlation information would lose that distinction. Observation provenance is also necessary to avoid counting the same evidence twice.

Before field claims, use the measured OCV table and test current/voltage offsets, filtered or correlated noise, time jitter, temperature variation, model mismatch and gradual or abrupt parameter changes. The very small matched-model errors here should not be used as a real-cell accuracy specification.
