# C0: outer linear constraints and exact verification of query bounds

Status: candidate proof, pending independent review. Depends on R0 and reviewed
D2/D4. This is a deterministic bounded-error certificate on a declared family;
it does not establish probabilistic coverage of H7's Gaussian uncertainty.

## Physical containment

Assume the true amplitude belongs to the finite public box l<=a<=u, q>0,
|B|<=H, and true stationary shape belongs to R0's public shape box. Assume each
selected measured voltage y differs from its exact physical voltage by at most
delta, including measurement/ADC/model error applicable to this family. Selection
is a fixed sample-count stride. All I/dt intervals propagate; unused voltage
observations do not become likelihood or independent evidence elsewhere here.

For a coefficient interval beta_j choose exact midpoint c_j and radius r_j.
Let M_j=max(|l_j|,|u_j|), e=sum r_j*M_j. Then

    |(beta-c)*a| <= sum |beta_j-c_j|*|a_j| <= e.

Together with |y-V0-beta*a|<=delta this yields the two exact linear inequalities
c*a<=y-V0+delta+e and -c*a<=-y+V0+delta+e. Thus the true amplitude satisfies all
retained strips, the public box and |B|<=H. SOC physical support is imposed using
z0-A_max*q>=0 and z0-A_min*q<=1, also satisfied by an admitted physical path.
Intersecting these constraints gives an outer polytope P containing the truth.
No Gaussian posterior or factorized probability interpretation is assigned to P.
Rate/amplitude correlations are conservatively relaxed, not counted as new data.

## Exact dual-bound lemma

Write the constraints as A*a<=b. For any exactly nonnegative lambda and objective
c, set r=c+A^T*lambda. For every feasible a in the public box,

    c*a = r*a-lambda^T*A*a >= r*a-lambda^T*b
        >= -lambda^T*b + sum_j r_j*(l_j if r_j>=0 else u_j).

The final expression is an exact rational lower bound on min_P c*a. A floating
solver is used only to propose lambda. Negative components are replaced by zero;
finite components are converted to their exact represented rationals. Any values
are valid after nonnegativity enforcement, so no solver optimality/convergence
or floating dual feasibility is required. A failed/nonfinite proposal uses zero.
The maximum of the proposed and zero-multiplier lower bounds remains a lower
bound. Apply the same construction to -c and negate it for an upper bound.

The implementation also obtains a candidate feasible point from a slack LP and
checks every exact inequality using rational arithmetic. Without a verified
witness it reports unresolved. This prevents an empty *outer* polytope from
yielding a misleading result. It does not prove the outer witness corresponds
to any actual shape or certify the physical premises; truth containment still
depends on those premises. A failure to find a witness is not proof of exclusion.

## Query and authorization theorem

For SOC use c=(1,0,0,0,-A,0,...,0). For reciprocal capacity use c=e_q. The dual
lemma encloses the full feasible ranges. If 0<qlo<=qhi, reciprocal monotonicity
gives Q in[1/qhi,1/qlo]. Crossed or nonpositive inverse-capacity bounds are not
authorized. Exact rational endpoints are authoritative; displayed binary64
endpoints are enlarged by nextafter if nearest conversion rounded inward.

Given finite ordered enclosure[L,U], accept any specified SOC point p only if
max(|p-L|,|p-U|)<=t. Accept a capacity point p for relative tolerance t in[0,1)
only if (1-t)*U<=p<=(1+t)*L. The reviewed D2 endpoint proof then gives the declared
error at this physical prefix. A certificate midpoint and the actual H7 point
are checked separately. Availability of the midpoint does not authorize another
point, and H7's covariance is never used to create or shrink P.

The result binds source recipe, current prefix, support, shape box, calibration,
voltage envelope and evidence stride. It concerns the current boundary only;
it is not transferable to an unobserved future or an aged cell without propagation
under qualified evolution assumptions. The two estimators may use the same
observations in parallel because no posterior is combined as independent data.

If the physical/measurement premises hold for an entire finite sequence, these
deterministic arguments apply at every selected query prefix. The pilot does not
establish those premises for a deployed population, a Gaussian noise process or
ten years. No reacquisition deadline is proved. Empirical useful authorization
on an informative fixture and refusal on a rest control test D4's distinction;
they do not instantiate its universal/probabilistic availability premises.
