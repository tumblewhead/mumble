# U1: joint fit and uncertainty consequences of representation defects

Premises: finite real matrices, fixed positive observation weights already applied
by whitening, Euclidean coordinates, and unconstrained quadratic objectives.
Prior rows may be included once if they are the same declared Gaussian prior in
both objectives. No nonlinear posterior, physical coverage or active-support claim
is made. The current continuous-shape model is linear in amplitudes conditional
on shapes; linearization in unknown shapes adds a separate approximation.

## Nuisance projection

Let a whitened residual be X*p+Z*n-y, where p is a target vector and n contains
nuisance amplitudes. Let M=I-Z*Z^+ be the orthogonal projector onto the complement
of the column space of Z (Moore-Penrose inverse). Assume S=X^T*M*X is positive
definite. Minimizing over n leaves 1/2 ||M*(X*p-y)||^2. An additive response defect
e independent of both p,n changes the profiled optimum by exactly

    delta_p=-S^-1*X^T*M*e.

Proof: the two profiled normal equations are S*p=X^T*M*y and
S*p_hat=X^T*M*(y-e); subtract. This retains the coupling to nuisance columns.
Using X^T*X instead silently assumes those columns known or orthogonal. If S is
singular, a unique unrestricted target optimum does not follow. With prior rows,
augment X,Z,y,e consistently (e has zero entries for unchanged prior rows).
The H3 charge-moment identity is the special two-column design with other
amplitudes fixed. Under full joint fitting, the residualized target columns are
what matter; raw charge covariance alone no longer determines the shift.

## Exact linear design-defect identity

Let baseline residual be A*b-y and baseline optimum b*, with A full column rank.
Write r=A*b*-y, so A^T*r=0. The approximate residual is
(A+D)*b-y+e0, with fixed D and e0. Define d=D*b*+e0 and B=A+D, assumed full rank.
At b*, the approximate gradient is

    delta_g=A^T*d+D^T*r+D^T*d.

The approximate Hessian is P_hat=B^T*B. Since the objective is quadratic,

    b_hat-b*=-P_hat^-1*delta_g.

Expansion and the two normal equations prove these identities. In particular,
value agreement d=0 at b* leaves a gradient defect D^T*r and can change precision.
Even if r=0 too, the precision may differ. For nonlinear models this algebra is
only a local design comparison: true Hessians include residual second derivatives,
and a fitted displacement needs an additional justified remainder bound.

## Information-normalized sensitivity and precision

Let P=A^T*A be positive definite, with symmetric positive square root. Set
Q=A*P^-1/2 and G=D*P^-1/2; Q^T*Q=I. Let epsilon=||G||_2<1. For any vector x,

    (1-epsilon)*||x|| <= ||(Q+G)*x|| <= (1+epsilon)*||x||.

Triangle and reverse-triangle inequalities prove this, yielding

    (1-epsilon)^2*P <= P_hat <= (1+epsilon)^2*P

in quadratic-form order. Inversion reverses that order. For any fixed local
query gradient j, its formal variances obey

    j^T*P^-1*j/(1+epsilon)^2
      <= j^T*P_hat^-1*j
      <= j^T*P^-1*j/(1-epsilon)^2.

The exact linear-fit identity also gives

    ||P^1/2*(b_hat-b*)|| <= ||P^-1/2*delta_g||/(1-epsilon)^2,
    |j^T*(b_hat-b*)| <= sqrt(j^T*P^-1*j)
                         *||P^-1/2*delta_g||/(1-epsilon)^2.

For the first bound substitute P_hat=P^1/2*C*P^1/2, whose C has minimum
eigenvalue at least (1-epsilon)^2. The second is Cauchy-Schwarz. These are exact
linear-algebra bounds under the premises; they do not assert a small epsilon.
Small entrywise D alone is insufficient when P has weak directions. If P is
singular, these inverse formulas are unavailable; adding an arbitrary diagonal
to pass the test changes the inference problem and is not this theorem.

## Repetition and shared overconfidence

Repeat an identical full-rank design and coherent defect N times, with no new
prior per repetition. The quadratic objectives both multiply by N, so fitted
displacement is unchanged. Formal covariance divides by N. Thus a fixed nonzero
query bias can grow as sqrt(N) in formal standard-deviation units, even with
matching precision ratios. Independent Gaussian observations are a premise for
interpreting that covariance statistically; repeated use of the same physical
observations is not independent evidence and is prohibited by ownership rules.
These are hypothetical fresh, identically designed blocks, not replay duplication.

Consequently the acceptance questions must include value defects, derivative
defects, information-normalized projections, nuisance coupling and query effects.
Matching two approximations' widths does not establish either physical coverage
or correct centering. Codebook/basis qualification must bound these defects over
its declared support before these inequalities become a deployment certificate.
