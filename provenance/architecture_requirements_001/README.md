# Reviewed architecture requirement decisions

On experiment/conditional-architecture-001, based on e354203, this step specifies
the architectural response to each of the ten open requirement items without
closing physical/platform/representation qualification by assumption. See the
[decisions](../../specifications/architecture_requirements_001/README.md) and
[machine-readable resolution](../../specifications/architecture_requirements_001/resolution.json).
Individual code blocks, estimator implementation and campaign defaults are unchanged.

The history design now distinguishes prior-free transition evidence from a joint
boundary message that includes the original prior and all ancestor evidence once.
An explicit evolution law carries past information to current state/health; a
centroid alone is not the history. The first synthetic evolution convention keeps
SOC/RC voltages/hysteresis continuous under the user's phenomenological equations.
Actual physical aging, state conventions and quantitative bounds remain unqualified.

coefficient dependencies and cross terms. Binary64 degree1/2/3 full tensor tables

and interrupts still need memory. This rules out that full cubic storage scheme
under the10240-byte complete target, not all possible sparse/compressed cubics.

revisions:

- [S1 review](S1_review_r1.json): exact measure/kernel composition, once-only prior
