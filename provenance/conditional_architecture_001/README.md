The failed arm remains quarantined; no diagnostic result is republished.

The immediate architecture questions are domain-aware fast updates and effective
nonlinear recovery. Simply broadening a polynomial domain changes its approximation
error; clamping a parameter changes inference. Neither is silently applied here.

## Fixed-shape control

The retained object packs the existing conditional response/composition factor.
All54 public common-query comparisons pass the declared numerical gates across
rest, multiscale and embedded loads at600/3600seconds. These are likelihood and
transport checks, not54 independent cells or accuracy/coverage trials.

The largest conditional/direct relative NLL difference is4.15e-10; the largest
scaled relative amplitude-gradient difference is1.28e-9 and precision difference
8.32e-14. Endpoint amplitude differences remain below1.76e-12. Direct reference
means binary64 C-model evaluation, not exact-real arithmetic. Costs, gradient
norms, precision norms and endpoint differences remain separate in the results.

The same queries expose nonzero H7 response approximation discrepancies. These
queries derive from the public prior before observations; they are not fitted
posterior centers. Their NLL differences cannot be read as estimation bias,
uniform error bounds or posterior probability errors.

No prior is fitted or discarded: this compares prior-free likelihoods at common
physical points. An unchanged original chart prior would add equally at those
points. The fixed-shape derivative includes the coupling between q=1/Q and
gamma_plus/minus at fixed gamma/Q. This does not create a Gaussian amplitude
posterior or justify fixing unknown rates in deployment.
